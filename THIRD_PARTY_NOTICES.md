# Сторонние компоненты

Код **Ambilight by Levurgi4** распространяется по лицензии MIT, текст которой
находится в файле `LICENSE`. Готовая portable-сборка Windows также содержит
сторонние динамические библиотеки, которые не переходят под лицензию проекта.

## Qt 6.10.3

Приложение динамически использует библиотеки Qt 6.10.3 и плагины из модулей
Qt Base, а также готовые переводы Qt. Qt принадлежит The Qt Company Ltd. и
другим участникам проекта Qt и в этой сборке используется на условиях GNU
Lesser General Public License version 3.

- полный текст LGPLv3: `LICENSES/LGPL-3.0-only.txt`;
- включённый в неё текст GPLv3: `LICENSES/GPL-3.0-only.txt`;
- SPDX-уведомления Qt и входящих в него сторонних компонентов:
  `LICENSES/Qt/qtbase-6.10.3.spdx` и
  `LICENSES/Qt/qttranslations-6.10.3.spdx`;
- официальный обзор лицензирования: <https://www.qt.io/licensing/>.

Qt собран как отдельные DLL. Пользователь может заменить библиотеки и плагины
в каталогах `bin` и `plugins` совместимой изменённой сборкой Qt и запустить
приложение с ними. Исходный код самого приложения и инструкция его сборки
находятся в публичном репозитории.

В assets каждого GitHub Release, начиная с v0.1.6, публикуются точные архивы исходного кода Qt,
соответствующие распространяемым библиотекам:

- `qtbase-everywhere-src-6.10.3.tar.xz`;
- `qttranslations-everywhere-src-6.10.3.tar.xz`;
- файлы `.sha256` для проверки обоих архивов.

Архивы содержат исходный код Qt, его собственные лицензионные файлы и
уведомления для встроенных сторонних компонентов. Ambilight by Levurgi4 не
вносит изменений в Qt.

## Microsoft Visual C++ Runtime

Portable-сборка содержит распространяемые библиотеки Microsoft Visual C++
Runtime, необходимые приложению, собранному MSVC. Эти файлы принадлежат
Microsoft и распространяются на условиях лицензии Visual Studio, а не MIT.
