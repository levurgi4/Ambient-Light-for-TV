# Материалы оформления

Оригинал логотипа **Ambilight by Levurgi4** находится в файле
`AmbiLight Logo.png`.

Предпочтительный вариант:

- имя файла: `logo.svg`;
- векторные контуры без привязки к отсутствующим системным шрифтам;
- квадратная область или достаточные поля для подготовки квадратной иконки.

Текущий растровый исходник:

- имя файла: `AmbiLight Logo.png`;
- прозрачный фон;
- цветовой профиль sRGB;
- размер 426 × 418 пикселей.

Служебные варианты создаются командой:

```powershell
python tools\prepare_branding.py
```

Для повторной генерации потребуется Pillow (`python -m pip install Pillow`).
Готовые файлы уже находятся в репозитории, поэтому для обычной сборки
приложения эта зависимость не нужна.

Скрипт не перерисовывает знак: он добавляет прозрачные поля до квадратного
формата и выполняет качественное масштабирование. Результаты:

- `logo.png` — каноническое квадратное изображение для документации;
- `desktop/assets/icons/app-icon.png` — ресурс Qt для окна и трея;
- `desktop/assets/icons/app.ico` — Windows-иконка с размерами 16–256 пикселей.
