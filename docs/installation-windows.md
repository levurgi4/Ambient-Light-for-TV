# Запуск Ambilight на чистой Windows 11

Эта инструкция разделяет два разных случая:

1. **Обычный запуск готовой portable-сборки** — подходит пользователю и не
   требует Visual Studio, Qt, CMake, Python или ESP-IDF.
2. **Сборка и прошивка из исходников** — нужна разработчику либо для первой
   прошивки новой ESP32.

Проект пока не выпускает подписанный установщик. Скачайте на странице
[GitHub Releases](https://github.com/levurgi4/Ambient-Light-for-TV/releases)
ZIP с portable-приложением и соседний файл контрольной суммы SHA-256.
Переносить и хранить нужно **всю распакованную папку**, а не только EXE-файл.

## Вариант A: запуск готовой portable-сборки

### Что установить

- Windows 11 x64 со штатными обновлениями;
- актуальный драйвер видеокарты NVIDIA, AMD или Intel с поддержкой D3D11 и
  DXGI Desktop Duplication;
- драйвер USB-UART CH9102X — только если Windows не создала COM-порт
  автоматически. Используйте официальный пакет WCH
  [CH343SER.EXE](https://www.wch-ic.com/downloads/CH343SER_EXE.html), который
  прямо поддерживает CH9102/CH9102X.

Qt, Visual C++ Redistributable и другие библиотеки отдельно устанавливать не
нужно: подготовленная portable-папка уже содержит необходимые Qt DLL,
плагины и runtime MSVC.

### Подготовка файлов

1. Скачайте из последнего GitHub Release архив
   `Ambilight-by-Levurgi4-v…-windows-x64.zip` и соседний файл `.sha256`.
2. При желании проверьте загрузку. В PowerShell выполните
   `Get-FileHash .\Ambilight-by-Levurgi4-v…-windows-x64.zip -Algorithm SHA256`
   и сравните результат со строкой в файле `.sha256`.
3. Распакуйте архив, например, в `C:\Programs\Ambilight by Levurgi4`.
4. Не переносите один EXE отдельно от каталогов `plugins`, `translations` и
   остальных файлов комплекта. Иначе Windows сообщит об отсутствующих Qt DLL
   либо приложение не найдёт платформенный плагин.
5. Запускаемый файл находится в
   `bin\Ambilight by Levurgi4.exe` внутри portable-папки.
6. Папка `Colour test` содержит изображения и видео для проверки реакции
   разных сторон, насыщенных цветов, градиентов и смены кадров.

### Проверка контроллера

1. Пока питание ленты 12 В выключено, подключите ESP32 к ПК исправным
   data-кабелем microUSB.
2. Откройте **Диспетчер устройств → Порты (COM и LPT)**.
3. Убедитесь, что появился `USB-Enhanced-SERIAL CH9102 (COMx)`.
4. Запомните номер `COMx`. Если устройства нет, попробуйте другой data-кабель
   и USB-порт, затем установите официальный драйвер WCH.

Для обычного запуска ESP32 уже должна быть прошита Ambilight-прошивкой. Если
это новая плата, сначала выполните раздел «Первая прошивка ESP32» ниже.

### Безопасный порядок первого запуска

1. Проверьте физическую схему по
   [руководству по подключению](hardware-wiring.md). Общая земля ESP32 и ленты
   обязательна; 12 В нельзя подавать на ESP32.
2. Подключите ESP32 к USB компьютера. Прошивка стартует в безопасном режиме
   `Off`.
3. Запустите `bin\Ambilight by Levurgi4.exe`.
   Номер запущенной сборки виден в заголовке окна. Начиная с версии 0.2.2
   вкладка эквалайзера называется **Звук**; если её нет, запущен старый EXE из другой
   папки — полностью закройте старый экземпляр в трее и откройте файл из нового
   portable-комплекта.
4. Откройте вкладку **Подключение**, нажмите **Обновить** и один раз выберите
   порт CH9102 вручную. Дождитесь состояния `Подключено — COMx`.
5. На вкладке **Светодиодная лента** до включения 12 В задайте фактическое
   число LED, порядок `RGB`, небольшую яркость и консервативный лимит тока.
   Для текущего прототипа безопасная отправная точка — 50% и 3000 мА.
6. Включите БП ленты 12 В. Не подключайте и не перепаивайте низковольтные
   провода под напряжением.
7. Нажмите **Настроить и проверить стороны**. Тестовая заливка остаётся
   включённой, пока открыто окно настройки. Сначала покажите все стороны:
   верх должен стать красным, правая сторона зелёной, низ синей, левая сторона
   оранжевой, а физический LED 0 — белым. Для точной проверки выберите заливку
   только верхней, правой, нижней или левой стороны белым. Исправьте число LED
   по сторонам, положение LED 0 и направление. Сам физический LED 0 всегда
   остаётся первым диодом после DI — настройка перемещает логические границы
   сторон относительно него.
8. Завершите проверку расположения, включите **Проверить белый** и настройте
   R/G/B. Затем завершите тест белого.
9. На вкладке **Экран** выберите телевизор, оставьте 60 FPS и автоматическую
   глубину для первого запуска. На вкладке **Основное** выберите Ambilight.
10. Для проверки музыки откройте вкладку **Звук**, оставьте системное
    устройство вывода и начальные параметры, затем нажмите **Запустить
    эквалайзер**. Режим «Звуки Windows + микрофон» открывает оба
    источника, но ничего не записывает. «Пружинная» динамика с 55% даёт
    умеренное затухающее покачивание; выберите «Плавная», если нужен точный
    отклик без перелёта. Индикатор уровня позволяет проверить источник даже
     без подключённой ESP32.
11. После проверки можно включить автозапуск и закрытие окна в трей.

При первом подключении автоматический режим намеренно не перебирает все
COM-порты. Сначала требуется ручное подтверждение платы. Если CH9102X не
предоставляет приложению надёжную уникальную идентичность, оставьте его
`COMx` выбранным вручную — это нормальный безопасный режим.

Настройки приложения хранятся отдельно в профиле каждого пользователя
Windows. При переносе уже прошитой ESP32 на другой компьютер заново прошивать
её не нужно, но на новом ПК потребуется один раз выбрать COM-порт и повторить
настройки экрана, раскладки ленты, яркости и баланса белого.

## Обычный запуск после настройки

1. Подключите ESP32 по USB.
2. Включите питание ленты 12 В.
3. Запустите приложение, если автозапуск выключен.
4. Убедитесь по индикатору внизу окна, что ESP32 подключена.

При закрытии окна в трей приложение продолжает работать. Для полного
завершения используйте **Выйти** в окне или меню значка в трее. После полного
перезапуска ESP32 текущая прошивка начинает с `Off` и ждёт приложение:
настройки пока не сохраняются во flash контроллера.

## Вариант B: сборка из исходников

### Инструменты для приложения Windows

Установите:

- Git for Windows;
- Visual Studio 2022 с workload **Desktop development with C++**;
- CMake 3.24 или новее;
- Qt 6.10.3, комплект **MSVC 2022 64-bit**, в стандартный путь
  `C:\Qt\6.10.3\msvc2022_64`.

Клонируйте публичный репозиторий, затем откройте PowerShell:

```powershell
Set-Location C:\Dev
git clone https://github.com/levurgi4/Ambient-Light-for-TV.git
Set-Location C:\Dev\Ambient-Light-for-TV
cmake --preset windows-release
cmake --build --preset windows-release
ctest --preset windows-release
$installDir = Join-Path (Get-Location) "out\install\windows-release"
cmake --install out/build/windows-release --config Release --prefix $installDir
& "$installDir\bin\Ambilight by Levurgi4.exe"
```

Запускайте установленный комплект из `out\install`, а не отдельный EXE из
`out\build`: только установленная папка гарантированно содержит все
необходимые Qt-компоненты.

### Первая прошивка ESP32

Для прошивки установите официальный
[ESP-IDF Installation Manager](https://dl.espressif.com/dl/eim/index.html)
и ESP-IDF 6.0.2. Откройте созданную установщиком консоль ESP-IDF PowerShell:

```powershell
Set-Location C:\Dev\Ambient-Light-for-TV\firmware
idf.py set-target esp32
idf.py build
idf.py -p COMx flash
```

Замените `COMx` портом CH9102X. После успешной прошивки закройте ESP-IDF
monitor и другие программы, использующие этот COM-порт: одновременно им может
владеть только одно приложение. Текущая аппаратная конфигурация использует
GPIO18 и должна применяться только к согласованной схеме из
`docs/hardware-wiring.md`.

## Если приложение не запускается или не управляет лентой

- Ошибка про `Qt6Core.dll`, `Qt6Widgets.dll` или `qwindows.dll` означает, что
  скопирован только EXE. Распакуйте или скопируйте весь portable-комплект.
- `ESP32: нет связи` — проверьте COM-порт, data-кабель, драйвер CH9102X и
  закройте Arduino Serial Monitor, ESP-IDF monitor и другие терминалы.
- Порт есть, но приложение его не выбирает автоматически — выберите его
  вручную один раз; для некоторых USB-UART ручной режим остаётся постоянным.
- Цвета перепутаны — для текущей ленты подтверждён порядок `RGB`.
- Лента светится, но ползунки не действуют — сначала проверьте индикатор
  `ESP32: подключена (COMx)` и включите **Проверить белый**.
- При запуске появляется старый интерфейс — удалите старую копию или ярлык и
  запускайте EXE из актуальной portable-папки.
